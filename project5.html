Gadget Store E-Commerce (React) 🛒

Project Summary from GitHub: A modern, responsive e-commerce web application built with React and Vite. It provides an intuitive gadget shopping experience featuring dynamic cart drawers, interactive wishlist filtering, live search queries, and smooth dark/light theme switching.

Tech Stack

React.js (Hooks & Components) Vite Fast Build Tool Custom CSS Variables & Theming Dynamic State Management Responsive Mobile First UI

Key Features

  • 🌓 Dark / Light Mode Toggle: Smooth theme transition powered by CSS variables and state persistence.
  • 🛒 Slide-out Cart Drawer:
    • Interactive on-card quantity controls (- / +)
    • Slide-in cart sidebar with item totals, subtotal calculations, and item counts
    • Instant increment, decrement, and item removal
  • ❤️ Wishlist Drawer & Filter:
    • Heart toggle on product cards with instant visual state feedback
    • Dedicated sliding Wishlist drawer accessible from the top navbar
    • Filter catalog to display wishlisted products only
  • 🔍 Search & Brand Filtering: Real-time case-insensitive search by product name and dynamic brand filtering dropdowns.
