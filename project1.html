Cybersecurity & Anomaly Detection

AI-Driven Hybrid Framework for Automated Threat Hunting

Project Summary from Resume: Built an advanced cybersecurity framework combining statistical anomaly detection with a rule-based intelligence engine to proactively identify both known and unknown threats in enterprise network traffic. Includes a real-time web dashboard for threat visualization and SQLite-based logging.

Key System Architecture

  • Statistical Anomaly Detection: Analyzes network packet entropy, packet frequency bursts, and unusual port access patterns.
  • Rule-Based Intelligence Engine: Matches known signature profiles (DDoS, port scanning, brute-force attempts) against active streams.
  • SQLite Logging Pipeline: High-throughput, lightweight event recording enabling fast historical incident investigations.
  • Real-time Dashboard: Clean user interface for security analysts with instant threat severity alerts.
