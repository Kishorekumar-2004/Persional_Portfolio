To-Do List App ✅

Project Summary from GitHub: A clean, fully functional task manager built with pure HTML, CSS, and vanilla JavaScript. Add tasks, edit them inline, mark as complete, and delete — all saved persistently in browser localStorage so your tasks survive page refreshes.

Tech Stack

HTML5 Semantic Structure CSS3 Flexbox & Dark Theme Vanilla JavaScript (ES6+) DOM Manipulation Browser LocalStorage API

Key Features

  • ➕ Add Tasks: Type and press Enter or click the Add button.
  • ✏️ Inline Editing: Click edit to modify and rename any active task directly.
  • ✅ Mark Complete: Toggle tasks done/undone with animated checkboxes and strikethroughs.
  • 🗑️ Instant Deletion: Quickly remove completed or unwanted tasks.
  • 🔍 Filter Tabs: Seamlessly switch between All, Active, and Completed views.
  • 💾 Auto-Save (LocalStorage): Automatic browser serialization ensures zero data loss.
  • 📊 Live Counter Stats: Real-time display showing total items and pending completion count.
