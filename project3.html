Personal Portfolio Website

Project Summary from Resume: A single-page personal portfolio built with HTML, CSS, and JavaScript showcasing technical skills, featured engineering projects, formal education, and verified contact channels. Features a clean layout, smooth navigation, and is easily deployable online.

Technologies Used

HTML5 Semantic Elements CSS3 (Grid & Flexbox) Responsive Media Queries Smooth Anchor Scrolling GitHub Pages Ready

Design & Architecture Principles

  • Zero Bloat: Built without heavy third-party CSS or JS frameworks, ensuring sub-second load times.
  • Strict Semantic Structure: Organized using modern HTML tags (<header>, <nav>, <section>, <article>, <footer>).
  • Responsive First: Designed with a fluid 1-column layout for mobile and clean multi-column layouts for desktops.
  • Standard-Compliant Form: Features semantic inputs, field labels, and HTML5 client-side validation attributes.
